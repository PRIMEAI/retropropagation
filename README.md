# Rétropropagation
Rétropropagation étape par étape

Animations interactives du cours **Apprentissage profond (deep learning)** de Moulay Akhloufi.
Chaque page est un fichier HTML autonome qui fonctionne directement dans le navigateur, sur ordinateur, tablette ou téléphone, sans installation.

🔗 **Toutes les animations du cours :** https://primeai.github.io/Apprentissage-Profond/
